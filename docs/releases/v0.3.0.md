# BDFR Advanced AutoRig v0.3.0 (preview)

The Vehicle Rig sidebar now includes **Test Rig Functionality**. Select a newly built, unanimated rig and click **Create Test Animation** to generate a short 73-frame demonstration. Detected doors, hood and trunk open and close on their hinge bones, while the wheels rotate through the existing wheel-roll control. Press Play in the Timeline to inspect the movement. Click **Remove Test Animation** to delete the preview actions and restore the previous frame range, current frame, wheel control and hinge poses.

Door, hood and trunk motion requires an **Advanced** rig with correctly detected, separately movable parts. A **Simple** rig demonstrates wheel rotation. The preview refuses an existing rig action or NLA tracks to preserve user animation. It creates animation controls, not realistic vehicle physics or collision.

Blender 4.5 integration checks cover both rig modes, wheel and hinge movement, cleanup and previous binding/suspension behavior. Try the preview on a copy of your own `.blend` file and inspect hinge placement before using it in production.
