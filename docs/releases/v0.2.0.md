# BDFR Advanced AutoRig v0.2.0 (preview)

Two rig modes are available in the **Vehicle Rig** sidebar:

- **Simple:** body, wheel, and steering controls, with rigid automatic component weights.
- **Advanced:** one or more suspension control bones per wheel and separate hinge bones for detected doors, hood, and trunk.

The **Bone Count** slider sets a target total in Advanced mode. The minimum needed for detected controls is always preserved; extra bones extend wheel suspension chains. The panel shows both minimum and actual count. Advanced rigs provide keyframeable **Front suspension** and **Rear suspension** travel sliders (scene units). Additional suspension bones can be posed individually.

This version retains the v0.1.1 fix that makes meshes follow the rig object. Existing v0.1.0 rigs can still use **Repair Existing Rig Binding**. To change a built rig from Simple to Advanced, build a new rig from an unrigged copy of the model.

Suspension provides animation controls, not spring simulation, collision or wheel-ground contact. Component detection is heuristic. Back up a `.blend` file and check detected parts before building a rig.
