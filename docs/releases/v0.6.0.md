# BDFR Advanced AutoRig v0.6.0

- Add an Airplane vehicle type with explicit propeller, landing gear strut, aileron, elevator, rudder and flap detection.
- Simple builds fuselage, landing wheel and propeller controls; Advanced adds movable flight surfaces, gear struts and suspension. Landing wheels near a strut follow that strut.
- Automatically steer the lone nose or tail wheel of tricycle or taildragger layouts; override steering per wheel in the analysis panel.
- Extend Test Rig Functionality to animate flight controls, folding gear, propellers and landing wheels.
- Keep existing vehicle rigging, binding repair and viewport FRONT direction indicator.

Install the attached add-on ZIP with Blender 4.2 or newer using Edit > Preferences > Add-ons > Install from Disk. Consult the README before rigging production aircraft: moving parts must be separate meshes or disconnected islands and hinge locations are estimates.
