# BDFR Advanced AutoRig v0.5.0

- Add a labeled viewport FRONT arrow when analyzing a vehicle. It follows the selected ±X/±Y direction and moves with the completed rig.
- Add a Show FRONT Arrow checkbox, and a button to create the arrow on older rigs. The arrow is hidden in renders.
- Keep automatic mesh binding, separate front/rear wheel controls, Simple/Advanced modes, suspension and animation preview from v0.4.0.

Install the attached add-on ZIP with Blender 4.2 or newer using Edit > Preferences > Add-ons > Install from Disk. See the README for guidance and limitations.
