## BDFR Advanced AutoRig v0.1.1 (preview)

Fixes a binding issue in v0.1.0: moving the `Vehicle_Rig` object in Object Mode did not reliably carry the vehicle meshes. New rigs now parent the selected vehicle hierarchy to the armature object while retaining world transforms and rigid component weights.

### Existing v0.1.0 rigs

Install the attached **BDFR_AdvancedAutoRig-0.1.1.zip**, select the existing `Vehicle_Rig`, and click **Repair Existing Rig Binding** in the Vehicle Rig sidebar. The operation reconnects meshes whose Armature modifier already targets that rig without rebuilding weights. If the rig was previously moved away from its meshes, return it to its original location first: repair preserves the current mesh positions.

### Validation and limits

This is a preview build. Automated Blender 4.5 integration checks cover rig-object movement, pose deformation, imported hierarchies and repair of an earlier rig. Try it on a copy of your `.blend` file. The add-on still relies on heuristic component recognition and cannot distinguish wheels fused into one contiguous body mesh.
