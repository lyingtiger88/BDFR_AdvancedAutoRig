# BDFR Advanced AutoRig v0.4.0 (preview)

This update addresses reports of an apparently detached vehicle rig and an older add-on UI continuing to appear after installation.

- The Vehicle Rig sidebar now visibly identifies the active add-on version. It reports how many mesh objects using the selected rig actually follow its Object transform. **Fix Existing Binding** reparents existing rigged meshes without moving their world positions. **Bind Selected Meshes** can explicitly bind separate vehicle meshes that lack an Armature modifier, using an existing matching vertex group or a rigid body/wheel/hinge group selected by the part name and proximity.
- After Analyze, wheel entries show front/rear and side labels. Each wheel has an Auto/Front/Rear override; the chosen axle drives steering and advanced suspension assignment. Verify the Forward direction and detected labels before building the rig.
- The Wheel roll slider is removed for newly created rigs. Wheel bones can be animated directly. **Test Rig Functionality → Create & Play Test** keyframes and immediately previews wheel rotation together with detected doors, hood and trunk. Existing rigs with a legacy wheel-roll driver still support the preview without exposing the old Roll slider.

**Updating:** Remove the old add-on in Blender Preferences, restart Blender and install `BDFR_AdvancedAutoRig-0.4.0.zip` using **Install from Disk**. The sidebar must show `BDFR Advanced AutoRig v0.4.0` at the top. If a previously moved rig is away from its vehicle, return it to its original location before running binding repair. The repair cannot reconstruct unknown geometry or recover edits to deleted mesh data.

This remains a preview. Blender 4.5 integration checks cover rig movement, a manually rebound mesh, wheel classification, hinge/wheel preview and preview removal. Test a copy of your `.blend` file before using it on production models.
