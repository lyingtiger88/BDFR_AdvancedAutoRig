# BDFR Advanced AutoRig — افزونهٔ بلندر v0.1.0

افزونه‌ای برای ساخت ریگ مکانیکی اولیهٔ خودرو، SUV، کامیون/اتوبوس، موتورسیکلت و دوچرخه در Blender 4.2 و جدیدتر.

## نصب

1. فایل `BDFR_AdvancedAutoRig-0.1.0.zip` را **از حالت فشرده خارج نکنید**.
2. در Blender به `Edit > Preferences > Add-ons > Install from Disk` بروید و ZIP را انتخاب کنید. در بعضی نسخه‌ها این گزینه زیر منوی گوشهٔ بالا سمت راست فهرست Add-ons است.
3. افزونهٔ **BDFR Advanced AutoRig** را فعال کنید. در نمای سه‌بعدی کلید `N` را بزنید و تب **Vehicle Rig** را باز کنید.

## کار با افزونه

1. همهٔ مش‌های وسیله یا آبجکت والدِ حاوی مش‌ها را انتخاب کنید. مدل باید محور عمودی **Z** داشته باشد.
2. نوع وسیله و جهت جلو را تعیین کنید. پیش‌فرض `+Y` است؛ `+X` و جهت منفی هم پشتیبانی می‌شوند.
3. روی **1. Analyze Vehicle** کلیک کنید. فهرست قطعات شناسایی شده را ببینید؛ نوع هر بخش را در همان فهرست می‌توانید تغییر دهید.
4. اگر نام‌گذاری مدل تشخیص را سخت کرده، یک یا چند آبجکتِ مجزا را انتخاب کنید، از **Mark Wheel/Body/Door/Hood/Trunk** استفاده کنید و دوباره Analyze بزنید. این برچسب روی آبجکت ذخیره می‌شود.
5. همان مش‌های اصلی را انتخاب نگه دارید و **2. Build Rig** را بزنید. آبجکت `Vehicle_Rig` ساخته می‌شود و به مش‌ها Armature Modifier و وزن‌دهی ۱۰۰٪ صلب برای هر بخش می‌افزاید.
6. برای حرکت کل وسیله، استخوان `Root` را در Pose Mode جابه‌جا کنید؛ `Body` برای حرکت بدنه است. با انتخاب ریگ، دو کنترل **Steering (degrees)** و **Wheel roll (degrees)** در پنل دیده می‌شوند. روی مقدار کنترل کلیک راست کنید و `Insert Keyframe` بزنید تا متحرک شود.

## تشخیص و محدودیت‌ها

- نام‌هایی مانند `wheel`, `tire`, `tyre`, `door`, `hood`, `bonnet`, `trunk` و چند نام فارسی تشخیص داده می‌شوند. در غیاب نام، چرخ با شکل، ابعاد و جایگاهش حدس زده می‌شود. رینگ و تایرِ هم‌مرکز به یک استخوان چرخ وصل می‌شوند.
- گزینهٔ **Find disconnected parts** مش‌های دارای جزیره‌های ناپیوسته را بررسی می‌کند. اگر تعداد رأس‌های یک مش از **Per mesh scan limit** بالاتر باشد، آن مش به‌صورت یک بخش بررسی می‌شود و هشدار می‌گیرد. جزیره‌ها در مدل شما جدا یا تخریب نمی‌شوند.
- اگر چرخ و بدنه در یک مش **به هم جوش خورده** باشند، هیچ مرز توپولوژیکی قابل اتکایی برای ریگ صلب وجود ندارد. آن‌ها را در Blender جدا کنید و دوباره Analyze بزنید. برای مدل‌های وارداتی، بازبینی فهرست پیش از Build ضروری است.
- درها، کاپوت و صندوق فقط با نام‌گذاری یا تعیین دستی شناسایی می‌شوند. محل لولا تخمینی است و در Edit Mode می‌توان استخوان را دقیق‌تر جابه‌جا کرد.
- این نسخه تعلیق، دیفرانسیل، فرمان‌بندی مکانیکی دقیق، فیزیک، اسکریپت حرکت روی مسیر و انیمیشن آماده تولید نمی‌کند. کنترل فرمان زاویهٔ یکسان به چرخ‌های جلویی می‌دهد.
- مشی که از قبل Armature Modifier دارد و دادهٔ linked library پشتیبانی نمی‌شود. قبل از کار، نسخه‌ای از فایل `.blend` نگه دارید؛ از Undo بلندر هم می‌توان برای بازگرداندن عملیات استفاده کرد.
- تا زمانی که برای یک ریگ فایل نمونهٔ واقعی در Blender آزمایش نشود، سازگاری همهٔ فایل‌های FBX/GLTF/OBJ تضمین نمی‌شود. اعتبارسنجی فعلی شامل بررسی نحوی و آزمون الگوریتم تشخیص است.

## Technical notes

استخوان‌ها / Armature bones: `Root`, `Body`, `Steer.F*`, `Wheel.*`, and optional `Door.*` / `Hood.*` / `Trunk.*`. Every detected connected component gets one rigid vertex group. Parts marked **Ignore** receive no armature weights. Object geometry and transforms are left intact. The add-on targets Blender 4.2+.
